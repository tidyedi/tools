Convention comparator

Upload two or more DLA/DLMS-style implementation convention PDFs -- suffix variants of the same base transaction set (315A vs 315B vs 315N, say) -- and see exactly what differs between them: segment requirement/usage/notes changes, a segment present in one but not another, an element's type or min/max, or a code added or dropped from a qualifier's list. Matched by each file's own position/ref numbering, not row order, so the comparison holds even if a convention's rows shifted around.

Nothing you upload is stored, logged, or sent anywhere. Every PDF is parsed in memory and forgotten once the response is returned.

Same best-effort DLA-IC-format parsing as Convention importer -- a convention from a different publisher or generator may parse only partially, or not at all.
